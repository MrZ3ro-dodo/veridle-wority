# AGENTS

Os PRDs devem ser sempre criados na raiz do projeto atual, seguindo o formato `docs/plans/{{YYYY-MM-DD}}-{{descrição}}.md`.

- Sempre mantenha o documento de requisitos na estrutura `docs/plans/`.
- O nome do arquivo deve refletir a data e a descrição curta do produto.
- Use este padrão também para qualquer nova versão do PRD do projeto em desenvolvimento.
- Antes de iniciar a implementação, verifique se o arquivo do PRD correspondente existe no diretório correto.
